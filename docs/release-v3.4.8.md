# v3.4.8 三极管封装上直接标出 E / C / B

## 问题

你说三极管模型上看不到 EBC。查下来不是「画漏了」，是**根本没有名字可画**。

引脚名的取值顺序是：

```
网表 pinInfo（KiCad 最准） → 属性面板手选脚序 → 都没有就标 1/2/3
```

嘉立创 / Protel 导入的三极管通常两样都没有 —— 网表里引脚名就是 `1/2/3`，
`pinOrder` 也是空的。于是落到最后一级，3D 上标的是三个数字，等于没有 EBC 标注。

## 改法

把「没有依据」这一档从「只标脚号」换成「按本封装的常见排布标出来」：

| 来源 | 3D 显示 | 颜色 |
|---|---|---|
| 网表 pinInfo | 网表给的名字 | 白 |
| 你在属性面板手选的脚序 | 逐脚角色 | 白 |
| **没选过脚序** | **本封装常见排布** | **暖黄** |
| 非三极管 | 脚号 | 白 |

各封装的常见排布：

```
TO-92 / TO-39   E-B-C
TO-220 / TO-247 B-C-E
TO-3            B-E-C
```

为什么要用两种颜色：**白色 = 有确切依据**（网表给的或你亲手选的），
**暖黄 = 只是先按常见排布标着**。这样你一眼能看出哪些字母是「软件猜的」，
而不是把猜的当成板上丝印去焊。

预设**只影响显示，不写进工程文件**。实物不符时，在右侧属性面板把脚序换成正确的一种即可。

顺带把字母放大了一档（TO-92 `0.62→0.80`，TO-220 / TO-3 `0.50→0.68`，
TO-39 `0.46→0.62`，TO-247 `0.55→0.72`）—— 以前三个字母又小又扁，
斜视下就是一个白点，这也是「看不到」的一部分。位置没动，仍贴在本体顶面之上。

属性面板的对照行也同步改了措辞：

```
脚1 E ｜ 脚2 B ｜ 脚3 C　（未指定脚序，3D 上按本封装常见排布 E-B-C 暂标，黄色；与实物不符就在上面换一种）
```

## 实测（打包后程序，读 3D 文字精灵的世界坐标）

```
Q1（TO-92，pinOrder = null）
  E   x=8.5  y=1.75  z=13.5   scale 0.80   ← 脚1
  B   x=7.5  y=1.75  z=13.5   scale 0.80   ← 脚2
  C   x=6.5  y=1.75  z=13.5   scale 0.80   ← 脚3
  Q   x=7.5  y=2.20  z=13.02  scale 1.80   ← 位号，与字母不重叠
```

字母底边 `y≈1.65`，本体顶面 `≈1.58`，不会插进模型里。

`pin_names.js` 从 52 项扩到 62 项：三种封装的预设排布、四种来源标记
（`pinInfo` / `manual` / `preset` / `number`）、导入器合成的脚号名归入 `preset`
（不冒充网表给的名字）、面板文案、四处按来源取色。

17 套测试全绿，`lint-lc --strict` 123 个函数，跑分 15476 零漂移。

## 怎么用

1. 点一下板上那颗三极管，右侧「元件属性」里看「三极管脚序」；
2. 如果字母是**黄色**，说明软件在按常见排布暂标 —— 拿实物封装图对一下；
3. 对不上就在下拉里换一种（六种排布：`EBC`/`ECB`/`BCE`/`BEC`/`CBE`/`CEB`）；
4. 换完字母变**白色**，就代表这是你确认过的映射，不再是默认假设。
