# 洞洞板布线 HoleRoute3D v3.4.1

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.4.1-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\HoleRoute3D`；
3. 双击 `ProtoRoute 3D.exe`，不需要装 Python / Node / 任何运行时。

> 必须解压**整个目录**：程序依赖同目录的 `*.dll`、`*.pak`、`locales\`、`resources\`，只复制 exe 跑不起来。
> 首次运行可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.4.1** 表示版本正确。

## 本版针对「删掉 0Ω 两端的线就报错」的排查结论

拿实际工程文件逐场景复现后，结论是：**0Ω 当导线的桥接是正常工作的**，
报错来自另外两个问题。

### 先说清楚 0Ω 到底连了什么

0Ω 电阻只把**它自己的 1、2 脚**连成一个节点。它的两端仍然要各自用铜箔接到本网络。
所以：

| 你做的操作 | 结果 | 是否正确 |
|---|---|---|
| 删掉 0Ω **两焊盘之间**那条跨接跳线 | 仍然连通（导电的就是电阻本体） | ✅ 正确，本版实测 R24 仍为 CONNECTED |
| 删掉 0Ω **通往网络**的那两段走锡 | 两端真的悬空了，DRC 报未连通、飞线重新出现 | ✅ 正确，这不是 0Ω 能补的 |

实测数字（你的工程，3 个 0Ω 元件）：

| 场景 | DRC 错误数 |
|---|---|
| 原样 | 13 → **本版修完后 9** |
| 删掉 R24 两脚之间的跨接跳线 | 9（无新增，R24 两端仍 CONNECTED） |
| 同上但把 R24 改成 1kΩ | 19（12 个 GND 引脚断开）——证明桥接确实在起作用 |
| 删掉通往网络的 6 段走锡 | 21（12 个 GND 引脚 + R24 两端真的断开） |

飞线侧也复核过：删掉跨接跳线后，没有桥接时 GND 需要 6 段飞线，有桥接时仍是基线的 5 段，
**飞线不会跨过 0Ω 元件画线**。

### 本版修掉的两个问题

1. **没有指派过网络的焊盘，不再被报成「错网短路」**
   以前会出现「错网短路：R25.1 期望 无网络，实际 $1N39」这种自相矛盾的错误。
   没有期望网络就谈不上错网，现在降级为「未使用引脚」警告，仍然在 DRC 面板里能看到。
   你的工程错误数从 13 降到 9。
2. **0Ω 引脚真的没连通时，DRC 文案直接告诉你原因**
   消息后面会追加「（0Ω 只把自身 1、2 脚连起来，这一端仍需要铜箔接到网络）」，
   不用再猜是哪儿的问题。属性面板的「0Ω 视为导线」标签也补了同样的说明。

### 还有一个限制要说明

0Ω 的桥接只在**两脚属于同一网络**时成立。你的工程里：

- `R24` 两脚都是 GND → 桥接生效；
- `R25`、`R26` **两脚没有任何网络**（手动加的元件，没指派过网络）→ 不建立桥接，
  DRC 只会提示「未使用引脚」。

如果你需要的是「0Ω 自动把两侧铜箔所属的网络合并成一个」，那是另一套网表合并逻辑，
本版没有做——需要的话告诉我，我按你的用法再加。

## 验证（本版实测记录）

用打包后的程序 + 真实鼠标事件、并直接读 DRC 结果复测：

- 原样：9 个错误（8 条是手工铜箔与网络重叠，1 条底层走锡重叠），R25/R26 两脚为「未使用引脚」警告；
- 删掉 R24 跨接跳线：仍是 9 个错误，`R24.1`/`R24.2` 保持 `CONNECTED`，GND 没有新增未连通；
- 同样的删除操作、把 R24 改成 1kΩ：19 个错误，12 个 GND 引脚 `REQUIRED_UNCONNECTED`；
- 删掉通往网络的 6 段走锡：21 个错误，12 个 GND 引脚与 R24 两端断开，文案带 0Ω 说明；
- 飞线段数：删跳线后有桥接仍是 5 段（= 基线），无桥接则 6 段。

自动化方面：16 套补丁回归全部 PASS（`v34_features.js` 扩到 78 项），
布局布线跑分 15476 零漂移。

## 升级注意

- 直接覆盖解压即可，**不需要迁移工程数据**；
- 剩下那 9 条错误是你手工铜箔与网络标签重叠造成的（`MANUAL` 铜箔压在 `$1N11` / `$1N32` / `$1N33` 等网络上），
  跟 0Ω 无关：把这些手工走锡删掉重画、或让自动布线接管，就能消掉。
