# v3.5.2 — 修正 Q1 基极/发射极映射（内测版）

> 替代 v3.5.1。此版本恢复正确排布：**脚1=B、脚2=E、脚3=C**。

## 为什么 v3.5.1 是错的

按您指出的电路关系重新核对：

| Q1 引脚 | 网络 | 同网络元件 | 角色 |
|---|---|---|---|
| 脚 1 | `$1N5` | **C2-1、R3-2、SW1-1** | **B 基极** |
| 脚 2 | `$1N4` | **R1-2** | **E 发射极** |
| 脚 3 | `+5V` | U1、SW1、U2 | **C 集电极** |

您提供的 `.enet` 对 Q1 明确给出：

```
FootprintName       S8050_SOT-23
Supplier Footprint  SOT-23
```

SOT-23 三脚 BJT 的标准排布是 `1=B 2=E 3=C`。因此：

- 基极 B 在脚 1，连接 C2/R3 的公共正极节点；
- 发射极 E 在脚 2，经 R1 连接；
- 集电极 C 在脚 3，连接 +5V。

v3.5.1 根据当前 3D 外形为 TO-92、且旧工程缺少封装字段，推成了
`1=E 2=B 3=C`，方向错误。此版已撤销该判断。

## 修复后的规则

1. 网表提供真实引脚功能名 → 直接使用；
2. 用户手动选择脚序 → 严格按选择；
3. 明确 `footprint` / `packageName` → 按封装判定；
4. 旧工程只有 `S8050_SOT_NPN`、没有 Footprint → 按 SOT-23 兼容处理；
5. 明确写 `TO-92` 的工程仍按 TO-92 处理，不会被 `value` 里的 SOT 字样带偏。

## 验证

- 使用真实 `Netlist_Schematic2_2026-11-15.enet` 验证 `$1N5` 同时连接 C2、R3、Q1；
  `$1N4` 只连接 R1 与 Q1；
- 打包后打开 `Untitled-Perfboard.json`，Q1 字母为 `B / E / C`；
- 21 套回归测试全绿；
- 自动布线评分 **15476 零漂移**。

## 飞线层说明

本次只修正字母角色，**不会改变飞线算法**。

您的工程里 Q1 从旧位置 `(20,38)，180°` 移到了 `(18,38)，360°`。
旧 `+5V` 跳线仍从 `(18,38)` 出发，但该孔现在属于 Q1-1（B），
而 Q1-3（C）在 `(20,38)`。旧铜箔与当前脚位不一致，所以飞线会按实际连通状态重画。

处理方式：删除 Q1 附近的旧走锡/跳线，再重新布线。若只点「继续布线」，
旧铜箔会被保留，不能修正这次错位。
