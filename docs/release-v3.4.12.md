# v3.4.12 — 三极管脚序改成按封装判定（内测版）

> ⚠️ 仍然是内测版，已知 / 未知缺陷都不少。重要工程请随时导出 JSON 备份。

## 这一版修了什么

**嘉立创网表里的三极管，B 和 E 被标反了。**

你给的 `Netlist_Schematic2_2026-11-15.net` 里 Q1 是 `S8050_SOT-23`（SOT-23 贴片），
软件却按 TO-92 的排布标成 `1=E 2=B 3=C`。按网表本身核对：

| 脚 | 所在网络 | 应该是 |
|---|---|---|
| Q1-1 | `$1N5`（R3-2、C2-1、SW1-A） | **B** 基极（分压 / 按键触发） |
| Q1-2 | `$1N4`（R1-2 → R1 → `$1N3` / PR1） | **E** 发射极（经电阻出定时网络） |
| Q1-3 | `+5V` | **C** 集电极 |

SOT-23 的 BJT 是 JEDEC 标准 **1=B 2=E 3=C**（S8050 / S8550 / MMBT3904 / BC817 都这样），
TO-92 才是 `1=E 2=B 3=C`。两者正好把 B 和 E 对调，所以看着「EBC 全乱」。

## 三层原因，都修了

**一、脚序按内部 kind 取，不按封装取。**
立创网表里没有引脚功能名（`pinInfo` 只有 `"1"/"2"/"3"`），唯一依据是封装；
而内部 kind 只有 5 种直插外形，SOT-23 被归成 `to92`，于是套了 TO-92 的 E-B-C。

现在先认封装族再取预设：

| 封装族 | 预设 | 说明 |
|---|---|---|
| TO-92 / TO-39 | E-B-C | 直插，平面朝自己 |
| TO-220 / TO-247 | B-C-E | 中间脚接散热片 |
| TO-3 | B-E-C | 金属壳大功率 |
| **SOT-23**（含 SC-70 / SOT-323 / SOT-523） | **B-E-C** | 贴片 BJT，1 脚是基极 |
| SOT-223 / SOT-89 / TO-252 | B-C-E | 带散热片，散热片与 2 脚同电位 |

认不出封装时才退回旧的 kind 预设。

**二、封装信息在导入时就被丢了。**
Protel（立创）转换器只写了旧式的 `(footprint "...")`，而解析端只认 KiCad 8 的
`(fields (field (name "Footprint") ...))`，所以 `packageName` 一直是空字符串 ——
网表里明明写着 `S8050_SOT-23`，程序却从来没看见。

现在两条都写，实测导入后 `packageName = S8050_SOT-23`。
组件本身没存封装名时，也会去 `importState` 里按位号补。

**三、属性面板文案和行为不符。**
下拉第一项原来写「未指定（只显示脚号）」，但实际行为早就改成按封装暂标了。
改为「未指定（按封装常见排布暂标）」。

## 界面上现在长这样

```
元件属性 → 三极管脚序：未指定（按封装常见排布暂标）
封装 SOT-23　脚1 B ｜ 脚2 E ｜ 脚3 C
（未指定脚序，按 SOT-23 常见排布 B-E-C 暂标，黄色；与实物不符就在上面换一种）
```

底部提示也同步：悬停 `Q1.1` 显示 `Q1.1（B） — 网络 $1N5`。

字母仍是**暖黄色** —— 意思是「按常见排布暂标，不是你确认过的」。
下拉里手动选一种（比如 `1=B 2=E 3=C`）后变白，表示「确认过了」。
换一种排布只影响标注，不写进工程文件的电气数据。

## 边界处理

- 封装族只在**三脚**时才算三极管。SOT-23 还有六脚版本（SOT-23-6），那种是芯片，不套 B-E-C。
- 优先级不变：网表引脚名 > 手选脚序 > 封装预设 > 只标脚号。
- **3D 外形没动**：SOT-23 器件仍显示为 TO-92 半圆柱（按你之前的要求「不要改模型」），
  只是三只脚的字母和面板文案按真实封装走。

## 如果你手上的型号还是不对

只有两种情况：

1. 封装名和实物不符（比如库里把 SOT-23 的器件命名成 SOT-223）；
2. 这颗管的厂家排布确实不是 JEDEC 标准。

两种都直接在属性面板的下拉里选一次即可，选中后字母变白、不再提示「暂标」。

## 升级提示

从 v3.4.11 及更早版本升级后，**已经保存的工程不用重新导入**：

- 老工程里没有封装名，但 `value` 字段（立创的 Device 名，如 `S8050_SOT_NPN`）还在，
  能据此认出 SOT-23；
- 想更准（区分 SOT-23 / SOT-223），重新导入一次网表即可 —— 现在封装名会存下来。
