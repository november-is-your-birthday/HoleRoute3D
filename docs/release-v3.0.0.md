# ProtoRoute 3D v3.0 中文增强版

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 本版基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.0.0-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\ProtoRoute3D`；
3. 双击 `ProtoRoute 3D.exe` 即可，不需要装 Python / Node / 任何运行时。

> 务必解压整个目录，不要只把 exe 复制出来——程序依赖同目录的 dll、pak、locales 与 resources。
> 首次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.0** 表示版本正确。

## 本版重点

### 1. 直接支持嘉立创 / 立创EDA 网表（本版核心）

以前只能用 KiCad 导出的网表。现在嘉立创 EDA 导出的 **Protel2 / Protel 99SE（.net）** 可以直接拖进软件：
导入时会自动识别 `PROTEL NETLIST` 文件头，在内存里转成 KiCad 格式再解析，无需任何外部转换工具。

导出步骤（详见压缩包内 `使用说明.txt`）：

- **嘉立创 EDA 专业版**：文件 → 导出 → 网表 → 格式选 **Protel2 / Protel 99SE** → 得到 `.net`
- **嘉立创 EDA 标准版**：文件 → 导出 → 网表 Netlist → 格式选 **Protel**
- 导出的 `.net` 直接拖进软件左侧「导入」区域

另外：网表缺少库字段（嘉立创网表常见）时，会按位号前缀推断元件类别，不再整批退化成排针。

### 2. 继续布线（增量布线）

新增「继续布线」按钮：**保留已有全部走锡与跳线**（包括上一轮自动布线的结果和手工修的线），
只给物理上还没连通的网络补线；已全部连通时只提示、不改动工程。补完按全量引脚重算 DRC。

### 3. 界面全面中文化 + 布局重排

- 工具栏、菜单、对话框、导入结果、DRC 输出（含错误码）共 100+ 处中文；
- 顶部由下拉菜单改为**常驻展开的分组方框**，窗口变窄时出现 `‹ ›` 横向滚动；
- 左侧栏重排：工程 → 导入 → DRC 检查 → AI 约束 → 导入结果 → 配色；元件/网络/引脚网络默认收起；
- 元件库改为真实 3D 模型缩略图，右上角可看大图。

### 4. 3D 视图与交互

- 焊盘双面常亮环（顶绿 / 底蓝，与焊盘同尺寸），四种颜色可自定义；
- **飞线层**：转到板子背面时用灰色直线显示尚未完成的连接，按铜的实际连通性判定；
- 走锡实时校验（起点黄环、共线黄 / 不共线红、右键取消），走锡强制正交、跳线不受限；
- 未放置元件在焊盘位置显示黄环提示落点；
- 右键旋转拆成 `+90° / −90°`；Shift 拖动不再弹出属性面板；
- 新增「清除布线」（只清走锡/跳线/DRC）与「一键清空」，都带确认。

### 5. 算法

- **自动放置约 2.3× 提速**（消除无意义的字符串构造、引脚孔位缓存、庭院构造去重），
  同时把评估预算从 2 候选/24 次提到 3 候选/36 次，实测跳线更少、走锡更短；
- **自动布线**增加 pull-tight 后优化（逐段拆开重布，更优才保留），拐弯减少。

## 已知限制

- 只支持洞洞板 / 面包板，**没有过孔与多层**；
- 网表只支持 KiCad S-expression 与 Protel2 两类；
- 元件库 23 类，识别不到的封装会退化成排针（可在属性面板手改脚距）；
- 元件只能 90° 旋转，没有镜像；
- AI 指令功能需要自备 API Key，且只在洞洞板自动放置对话框里出现。
