# 洞洞板布线 HoleRoute3D v3.4.0

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.4.0-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\HoleRoute3D`；
3. 双击 `ProtoRoute 3D.exe`，不需要装 Python / Node / 任何运行时。

> 必须解压**整个目录**：程序依赖同目录的 `*.dll`、`*.pak`、`locales\`、`resources\`，只复制 exe 跑不起来。
> 首次运行可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.4.0** 表示版本正确。

## 本版四项改动

### 1. 布线时不再被网络提示框挡住落点

以前鼠标一停在引脚上，就会弹出「R5.1 — 网络 GND」的浮框。选择模式下这很有用，
但**走锡 / 跳线 / 删线**时你的光标本来就贴着孔位在移动，浮框正好压在落点上。

现在这三个模式里一律不弹，回到「选择」模式立刻恢复。

### 2. 布线时误点元件，不再弹出右侧属性面板

走锡时手一抖点到元件，原来会把它选中、右侧栏整块刷出来，落孔操作也被打断。

现在这三个模式下点中元件不会产生任何选择动作：选集不变、侧栏不弹、右键菜单也不出。
只有回到「选择」模式，点击元件才会像以前一样选中它。

### 3. 板子四个方向都能就地增删行列

视口四边各有一组按钮：

| 位置 | 按钮 | 效果 |
|---|---|---|
| 上边 | `＋行` / `－行` | 在上方加一行 / 删掉最上一行 |
| 下边 | `＋行` / `－行` | 在下方加一行 / 删掉最下一行 |
| 左边 | `＋列` / `－列` | 在左侧加一列 / 删掉最左一列 |
| 右边 | `＋列` / `－列` | 在右侧加一列 / 删掉最右一列 |

几条明确规则：

- **往左、往上加**时，新的一行/列加在空的一侧，已有元件、走锡、跳线**整体平移 1 格**——
  不用担心加完之后所有东西错位；
- **往右、往下加**只把尺寸 +1，坐标原地不动；
- **缩小时会先检查**：被删的那一行/列上还有元件、走锡或跳线时直接拒绝，
  并告诉你是什么占着（例如「最左一列还有 C1，先移开再删除」），不会静默丢件；
- 尺寸范围沿用 5–150，面包板不走这条路径（它的尺寸由模块数决定）；
- 尺寸变化后会自动清掉已经失效的 DRC 结果，并提示重跑。

### 4. 零欧电阻直接当导线

手动加一个电阻、参数填 `0`（或 `0R` / `0R0` / `0Ω` / `0.0` / `0 ohm` / `0欧`），
并且它的 1、2 脚在**同一个网络**上时，程序把它当导线：

- 飞线不再在这两个脚之间画一根线；
- 自动布线 / 继续布线不会为这两个脚再铺一段多余铜箔；
- DRC 不会把它们报成未连通；
- 属性面板会显示「0Ω 视为导线」标签。

两点说明：

- **不写假铜箔**：桥接只存在于喂给布线器和 DRC 的入参里，不落盘、不渲染。
  所以之后挪动或删掉这个电阻，不会在旧孔上留下幽灵铜箔。
- **跨网络不算**：如果两个脚分属两个不同网络，那两个网络本来就是分开的，元件本体就是桥，
  飞线本来也不会跨网络画线——这种情况不需要额外处理。

## 验证（本版实测记录）

用浏览器级真实鼠标事件驱动打包后的程序复测：

- 选择模式下悬停引脚 → 提示框显示 `R5.1 — 网络 GND`；切到走锡，同一位置 → 提示框不可见；
- 走锡模式点中元件 → 选集不变（1 → 1），右侧栏不弹；
- 四边按钮全部就位（`＋行/－行 ×2、＋列/－列 ×2`）；右加一列 `24 → 25`；
  左加一列后所有元件整体 `+1` 格（C1 `7,38 → 8,38`）；两次 `Ctrl+Z` 完全还原；
- 零欧判定：`0R`→0、`0Ω`→0、`10K`→10000、`100uF`→不是电阻值；
  把 R1 在内存里改成 `0R` 且两脚同网 → 生成 1 条桥接 `(18,41)-(21,41)`；拆成两个网络 → 0 条；
- 全程工程数据与验证前完全一致（26 元件 / 20 网络 / 81 走锡 / 6 跳线 / 24×50）。

自动化方面：16 套补丁回归全部 PASS（新增 `v34_features.js` 69 项），
布局布线跑分 15476 零漂移。

## 升级注意

- 直接覆盖解压即可，**不需要迁移工程数据**（工程仍存在本机 `localStorage`，键名未变）；
- 板上已有的元件不会被自动识别成 0Ω：需要你在属性面板把参数改成 `0` 之类，
  并且确认两个脚已划到同一网络。
