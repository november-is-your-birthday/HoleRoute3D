# v3.5.3 — 三极管字母对位、面板孔位对照、LED 负极竖线（内测版）

本版只改 3D 标注与属性面板文案，**布线算法零改动**（回归评分仍为 15476）。

## 1. 三极管字母摊到各自脚位上方

旧版把外侧两个字母往中间收了 0.48 格，导致 B / C 看着不在自己那只脚上方，
中间的 E 反而最准，容易被读成「中间那只脚是 B」。

- 修改前：字母相对位置 `-0.52 / 0 / +0.52`，脚位 `-1 / 0 / +1`
- 修改后：`-0.74 / 0 / +0.74`，与脚位对齐

## 2. 属性面板新增「孔位 + 网络」对照

选中三极管后，脚序对照行同时给出孔位与网络，可直接对实物核对：

```
封装 SOT-23　脚1 B（孔18,38 · $1N5） ｜ 脚2 E（孔19,38 · $1N4） ｜ 脚3 C（孔20,38 · +5V）
```

## 3. LED 负极标记：整圈黑环 → K 侧黑色竖线

整圈黑环是 360° 对称的，**不能表示方向**。现改为在负极那一侧的壳体表面
贴一条黑色竖线，随元件一起旋转，对应实物 5 mm LED 负极侧的平切面。

负极脚的判定顺序：

1. **电路拓扑优先**：一脚经电阻到 GND、或直接落 GND → 该脚是负极；
   一脚接 VCC / +5V → 该脚是阳极。
2. 判不出来再退回网表引脚名（C / K / A）。
3. 都没有时退回行业约定脚 1。

**为什么必须看拓扑**：立创部分 LED 符号的 C/A 名字与封装焊盘对不上。
本工程网表写 `LED1 pin1 name=C`，但 pin1 接的是 CD4017 的输出、
pin2 才是十颗 LED 共用并经 R5 到 GND 的一侧，pin2 才是负极。
首版按符号名画到了正极上，现已按拓扑纠正（实测竖线位于脚 2 一侧）。

二极管不变：黑环套在 K 端，本身就带方向。

## 关于「飞线层与连线不一致」

本轮排查确认这与字母无关：工程中 Q1 被移动 / 旋转后，旧走锡与跳线仍留在原孔位。
例如 `+5V` 跳线从 `(18,38)` 出发，而该孔现在是 Q1 脚 1（基极 `$1N5`），
真正的集电极 `(20,38)` 反而没有 +5V 铜箔，于是飞线重新出现。

处理方式（二选一）：

- 把 Q1 转回 180°、挪回 `(20,38)`，旧铜箔立刻重新对齐；
- 或用「删线」清掉 `(18,38)`、`(19,38)`、`(20,38)` 上的旧走锡与跳线后再重新布线。
  注意「继续布线」只补线、不清理旧线，必须先删。

窗口标题显示 `ProtoRoute 3D v3.5.3 内测版` 即为本版。
现有工程无需迁移，直接打开即可。

仍为内测版，重要工程请随时导出 JSON 备份。
