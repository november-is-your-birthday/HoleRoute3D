# 洞洞板布线 HoleRoute3D v3.2.4

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.2.4-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\HoleRoute3D`；
3. 双击 `ProtoRoute 3D.exe`，不需要装 Python / Node / 任何运行时。

> 必须解压**整个目录**：程序依赖同目录的 `*.dll`、`*.pak`、`locales\`、`resources\`，只复制 exe 跑不起来。
> 首次运行可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.2.4** 表示版本正确。

## 本版（3.2.4）修复

### 1. 改网后「假短路」——本次最重要的一项

在左侧「网络连接」面板把一个引脚划到别的网络（拾取 / 手动添加 / 删除该引脚）后，
此前只清除**目标网络**的走锡，引脚**原来所属网络**的走锡与跳线仍留在板上。
这些铜箔依旧压在这个引脚孔上，而孔已经归属新网络 —— 物理上把两个网络连成一片，
重跑 DRC 会报「错网短路（`WRONG_NET_SHORT`）」与「网络间短路（`SHORT_BETWEEN_NETS`）」，
很容易让人误以为是自己接错线。

- 现在：凡引脚组成变动的网络（目标网络 + 所有被移走引脚的源网络）**统一清除**走锡 / 跳线 / 失败记录
  与旧 DRC 结果，并在「DRC 检查」栏提示「网络 A、B 的引脚已变更，该网络的走锡 / 跳线已清除，请重新布线」；
  被移空的源网络一并删除，不留空壳。
- 实机对比（同一操作：把 R3.2 从 `$1N5` 划到 `GND`）：修复前 9 个错误里含 2 处短路；
  修复后 9 个错误全部是「应连未连」，短路消失 —— 这正是清铜后应有的结果。
- 顺带加固：打开旧版本导出的工程 JSON（`routing` 缺少 `jumpers` / `failedNets`）不再抛异常。

### 2. 自定义封装面板的缩略图一直是占位图

「元件库 → 自定义封装」里的预览图此前始终是灰色占位 SVG，因为离屏渲染出的模型图没有回填目标。
现已与元件库卡片同一机制，1 秒内即显示真实 3D 模型缩略图。

## 自 v3.0.0 以来的主要变化

### 自定义封装（开发板 / 模块）

- 新增「自定义封装」面板：填名称、每排脚数（2–40）、排距（3–8 孔），生成 2×N 双排封装，
  可保存到库复用；排距 6 孔 ≈ 15.24 mm，正好覆盖 Nano / ESP32 / Pico 这类模块的双排孔距。
- 放不下当前洞板时「放置」按钮直接禁用并给出提示（此前只能事后靠 DRC 报错）。

### 软件内网络编辑

- 侧栏新增「网络连接」：新建网络（可自动编号）、快捷建 `GND` / `5V`、重命名式删除引脚、
  整个网络删除；也可以选择元件与脚号手动加入网络。
- **在 3D 板上点引脚拾取**：进入拾取后光标到哪个引脚就高亮哪个，点一下即加入该网络，
  `Esc` / 右键结束；不需要先跑网表就能手搓连接关系，飞线 / 自动布线 / DRC 立即可用。

### Multisim 报告导入

- 支持 NI Multisim 的 **Wire List（连线表）+ Cross Reference（交叉引用报告）** 双报告导入，
  两份一起拖入即可；电源 / 地符号自动忽略，`U1A/U1B` 多单元自动归并，`A/K`、`C/B/E` 字母脚自动重编号，
  DIP 脚数按封装名（`DIP8` / `DIP 8` / `8-DIP`）提取。
- `.cir`（SPICE）不支持并给出原因：SPICE 网表不含引脚号。

### 嘉立创 EDA 导入的持续修正

- 电解电容与普通电容区分：封装含 `ELE / TANT / RADIAL` 或值形如 `10uF`（且不是 0402/0603/0805 等贴片尺寸）
  判为电解电容（`Device:CP`），此前一律渲染成同一种普通电容。
- 轻触按键的**字母脚**（`SW1-A` / `SW1-B`）不再被静默丢弃，按「数字脚保持原编号、字母脚顺延」重编号，
  并按封装 / 值里的 `KEY / TACT / PUSH / BUTTON / 轻触` 识别为 3D 轻触按键（此前误判为拨动开关）。
- Multisim 与嘉立创两套通道的边界情况批量修复：引脚缓存跨批次污染、位号白名单漏项、
  多单元折叠的引脚冲突、坏文件不再拖垮整批导入等 13 项。

### 交互

- 工具栏新增「透视」按钮（透过板体看背面走线，快捷键 `T` 仍然可用）。
- 修复引脚点选坐标公式写反导致默认视角下点选 100% 失效（P0）。

## 升级注意

- **工程文件兼容**：`v2.0.0` 起的工程 JSON 都可直接打开；本版只是让缺失 `jumpers` / `failedNets`
  的旧工程不再报错。
- **窗口标题变化**：由 `ProtoRoute 3D v3.0` 改为 `ProtoRoute 3D v3.2.4`，便于确认运行版本；
  压缩包与 exe 名称沿用上游内部命名。
- 若你在旧版本里用「网络连接」改过网络，建议升级后**重跑一次 DRC**，确认没有被旧逻辑留下的残留铜箔。

## 已知限制

- 只支持洞洞板 / 面包板，没有过孔与多层；
- 网表来源：KiCad `.net`、嘉立创 Protel2 `.net`、Multisim 双报告；SPICE 不支持；
- 元件库 23 类，不认识的封装退化为排针（不影响布线与 DRC，只影响观感）；
- 元件没有镜像功能，只能 90° 旋转；
- AI 指令功能需要自备 API，仅在洞洞板「自动放置」对话框内。
