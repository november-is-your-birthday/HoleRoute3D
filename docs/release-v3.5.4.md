# v3.5.4 — 修正三极管 3D 引脚排布：基极落到中间孔（内测版）

## 问题

用户指出：**三极管中间才是 B 基极**，而软件一直把 B 画在最左边，
「3D 模型和引脚定位仍然是错误的」。

根因不是字母画错，而是**孔位归属**：

- 网表的脚号按符号排：Q1 是 SOT-23 口径 `1=B、2=E、3=C`；
- 3D 模型是 TO-92，而 TO-92 实物的引脚顺序是 **E-B-C**
  （平面对自己、引脚朝下，从左到右）——基极在中间；
- 旧实现按脚号 1/2/3 直接排孔，基极（脚 1）于是落在最左边的孔上，和实物差一位。

## 修正

新增引脚排布校正：把脚号按**角色**映射到模型的物理槽位
（E 的脚落 E 的槽位、B 落 B 的槽位、C 落 C 的槽位），
`position` 同步平移，三个孔的集合不变，只重排归属。

本工程 Q1 调整后：

| 孔位 | 修正前 | 修正后 |
|---|---|---|
| (18,38) | 脚1 B | **脚2 E**（经 R1） |
| (19,38) | 脚2 E | **脚1 B**（基极，$1N5 接 C2/R3/SW1） |
| (20,38) | 脚3 C | 脚3 C（+5V） |

3D 上从左到右因此变成 **E — B — C**，基极居中，与实物一致。

## 边界

- 幂等：排好后再跑不会翻来翻去；已经是 E-B-C 的不动；
- 旋转（含 180°）后仍对齐，孔位集合不变；
- 属性面板的手选脚序优先生效，同样按实物排布落孔；
- TO-220 / TO-247 / TO-3 / TO-39 按各自的物理排布映射（B-C-E、B-C-E、B-E-C）；
- 只改数据排布，**布线算法未动**（回归评分仍为 15476，零漂移）。

## 说明

如果你手上的管子是 C-B-E 排布（例如 BC547，平面对自己时 C 在左），
在属性面板把脚序改成 `1=C 2=B 3=E` 即可，程序会按你选的排布落孔。

## 安装

下载 `ProtoRoute3D-v3.5.4-cn-win-x64.zip`，解压后运行 `ProtoRoute 3D.exe`。
窗口标题显示 `ProtoRoute 3D v3.5.4 内测版` 即为本版。
现有工程直接打开即可，脚位会在打开时自动校正；保存后写回新排布。

仍为内测版，重要工程请随时导出 JSON 备份。
