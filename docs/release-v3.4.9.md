# v3.4.9 内测版标识

## 为什么发这一版

这个软件是在上游 `Perfboard-AutoRoute-3D` 2.0.0 的压缩包上打补丁改出来的。
功能一直在加，但没有经过完整的回归验证 —— 自动布线的结果不保证最优、DRC 可能漏报或误报、
导入器对部分网表格式兼容不全、撤销/删除的边界情况可能丢数据。

如果不写清楚，用户会默认「软件算出来的就是对的」，拿去做板、焊接，出了问题先怀疑自己。
所以这一版不加功能，只把「这是内测版」标到不可能看不见。

## 标在哪

| 位置 | 内容 | 何时可见 |
|---|---|---|
| 顶栏品牌名右侧 | 红色 **内测版** 标签（悬停有完整提示） | 常驻 |
| 窗口标题 | `ProtoRoute 3D v3.4.9 内测版` | 常驻 |
| 空面板 | 红字「重要工程请随时导出 JSON 备份」 | 没有打开工程时 |
| 启动提示条 | 6 秒提示，提醒先导出留档再反馈 | 每次启动 |

顶栏那枚标签是 `#c0392b` 红底白字，字号 10px、圆角 8px，紧贴 `ProtoRoute 3D` 之后，
在深色和浅色主题下都能看清。样式由 `__lcStyleOnce` 注入，不依赖外部 CSS。

## 给使用者的三句话

1. **别把它当唯一依据**：焊之前按原理图自己核对一遍，尤其是三极管脚序、网络连通性。
2. **随时导出备份**：标题栏右侧「导出工程 JSON」，出问题能回退。
3. **反馈请带工程**：保留 JSON 与复现步骤，比一句「布线不对」有用得多。
