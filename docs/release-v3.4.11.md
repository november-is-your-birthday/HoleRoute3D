# v3.4.11 二极管 / LED 的负极标黑环

## 改了什么

**二极管**和 **LED** 的 3D 模型上，负极（阴极 K）现在有一圈黑色环带。

## 哪只脚是负极

按两级判定：

1. **网表给了引脚名** → 找 `K`（或 `C`）；如果只给了 `A`，就取另一只脚。
2. **没有名字**（导入器常把引脚名合成为 `"1"`/`"2"`）→ 按行业约定取**脚 1**。
   KiCad 与立创 EDA 的二极管、LED 符号都是 `pin1 = K`、`pin2 = A`。

所以如果你的库是反的（`pin1 = A`），标记会落在错误的一端 —— 那种情况下请在网表里
把引脚名改成 `K`/`A`，软件会按名字走。

## 二极管

K 端套一圈黑色环带，直径 0.472（本体 0.42），宽 0.2。

顺带修了一个旧问题：原代码里本来就有个环，但它是**金属色**、而且装在 **A 端** ——
既标错了方向，又因为颜色接近本体而看不出来。现在改到 K 端并换成近黑。

**为什么环带两侧有两条细银边**：二极管本体是 `#1F2A2B`（深青黑），纯黑环在它上面会糊成一片，
放大截图也分不清。加两条 0.009 高的银边后，「黑带 + 银边」能把环的边界显出来 ——
实物二极管上的阴极环本身也是黑色带反光边的样子。

## LED

底座外圈（半径 0.752，底座 0.74）套一圈黑色环带，高 0.075。

这一处改了两版：

- **第一版做的是竖线**，贴在底座外侧、朝向 K 脚。实测发现线只朝向一侧，
  相机转到背面就完全看不见（截图里只剩一道模糊暗纹）。
- **改成整圈环**：任意角度都能看到，也和二极管那边一致。

另外发现原来那条白色细条（`__lcLedBar`）**整条埋在底座内部** —— 它偏离中心 22%、长 0.46，
而底座半径 0.74，从来没露出来过。已删除。

## 实测

打包后程序，读 3D 场景里带 `__lcCathodeMark` 的对象 + 截图放大核对：

```
二极管 D1/D2   CylinderGeometry @ K 端   环直径 0.472，两侧银边 0.009
LED ×8         CylinderGeometry @ 底座   环直径 0.752，高 0.075
```

截图放大后：二极管左端（脚 1 = K 一侧）是一圈清晰的黑色箍；LED 底座下沿绕满一圈黑环。
