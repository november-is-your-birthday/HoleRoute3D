# 洞洞板布线 HoleRoute3D v3.3.1

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.3.1-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\HoleRoute3D`；
3. 双击 `ProtoRoute 3D.exe`，不需要装 Python / Node / 任何运行时。

> 必须解压**整个目录**：程序依赖同目录的 `*.dll`、`*.pak`、`locales\`、`resources\`，只复制 exe 跑不起来。
> 首次运行可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.3.1** 表示版本正确。

## 本版重点：多选真正可用了

v3.3.0 加了 Ctrl 多选，但真实操作下不好用。这一版把它修到能用，并且**不再需要先拔起才能拖动**。

### 修掉的三处交互断点

| 现象 | 原因 | 现在的行为 |
|---|---|---|
| 多选后拖动，只有点住的那一个动 | 拖动必须按 `Shift`，而 `Shift` 在旧逻辑里表示「不选中元件、改拖引脚」，按下瞬间就把整个选集清空了 | `Shift` 拖动时选集保持不变，整组同步平移 |
| Ctrl 点第二个元件时常点空、视角还歪了 | three.js 的视角控制库把 `Ctrl + 左键` 映射成平移，每次 Ctrl 点选都会带动相机 | Ctrl 按下时暂时关掉视角平移与旋转，松手即恢复；实测视角零漂移 |
| 好不容易选了几个，点偏一下全没了 | Ctrl 点在空白处会走「清空选择」分支 | Ctrl 点空白保留已有选择；只有普通点击空白才清空 |

> 补充说明：上面第一条只修一半是不够的——点击元件有两条命中路径（点中引脚环 / 点中元件体），
> 首次点击元件基本都走后者。两条都改了才生效，这一点是第一轮修完实测才发现的。

### 拖动不再要求先拔起

`Shift + 拖动` 可以直接移动**已放置**的元件，单个和多选一致，不用先按 `U` 拔起来。
移动后引脚离开原孔，程序会自动提示「引脚位置已改变：原走锡 / 跳线还在旧孔上，请重跑 DRC 或重新布线」。
想彻底重排布局时，先 `Shift+U` 全部拔起会更顺手。

### 怎么用（速查）

| 操作 | 按键 |
|---|---|
| 加选 / 减选 | 按住 `Ctrl` 点击元件（`Ctrl` 点空白不再清空） |
| 整组移动 | 按住 `Shift` 拖动其中任意一个 |
| 整组旋转 90° | 拔起后按 `空格`（顺时针）或 `R` |
| 整组拔起 / 放回 | `U` / `M`；全部拔起 `Shift+U` |
| 整组删除 | `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |

整组操作只记一步撤销，`Ctrl+Z` 一次全部回退。

## 验证（本版实测记录）

用浏览器级真实鼠标 / 键盘事件驱动打包后的程序复测，不是只跑单测：

- 普通点 C1 → `[C1]`；`Ctrl` 点 R1 → `[C1,R1]`；`Ctrl` 点 Q1 → `[C1,R1,Q1]`，板中心投影全程恒定；
- `Ctrl` 点空白 → 仍是 3 个；`Ctrl` 再点 R1 → `[C1,Q1]`；
- **不拔起**直接 `Shift` 拖动 C1（+4,+3 孔）：C1 `7,40→11,43`、Q1 `20,40→24,43`、R1 `16,42→20,45`，
  其余 20 个元件位置不变，`mounted` 保持 23，并给出重跑 DRC 的提示；
- 先拔起再拖：三个元件同样同步平移，选集保持 3。

自动化方面：15 套补丁回归全部 PASS（`multi_select.js` 由 13 项扩到 34 项），
布局布线跑分 15476 零漂移，`check.js` / `rats-check.js` 全绿。

## 升级注意

- 直接覆盖解压即可，**不需要迁移工程数据**（工程仍存在本机 `localStorage`，键名未变）；
