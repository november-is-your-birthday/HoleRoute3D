# 洞洞板布线 HoleRoute3D v3.2.5

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.2.5-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\HoleRoute3D`；
3. 双击 `ProtoRoute 3D.exe`，不需要装 Python / Node / 任何运行时。

> 必须解压**整个目录**：程序依赖同目录的 `*.dll`、`*.pak`、`locales\`、`resources\`，只复制 exe 跑不起来。
> 首次运行可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.2.5** 表示版本正确。

## 本版（3.2.5）修复：只连了几个脚的芯片被当成「少脚元件」

**症状**：一个 DIP-8 的 NE555，原理图里只用到 1、2 脚（其余脚悬空），嘉立创网表导入后
3D 元件变成 **2 脚**的 DIP —— 脚距、焊盘位置、DRC 全都按 2 脚算，和实物对不上。

**原因**：Protel / 嘉立创网表**没有 `libparts` 段**（KiCad 网表有）。软件只能拿网表节点反推元件，
于是把「最大已连脚号」当成脚数：1、2 脚入网 → 2 脚 DIP。封装名 `DIP-8_...` 明明写在文件里，
但以前只用来判断元件类别，没参与脚数推导（Multisim 通道有这一步，嘉立创通道漏了）。

**修复**：

- 对 IC 类位号（`U` / `IC` / `A`），从封装名解析脚数：`DIP-8_L9.8-W6.5-P2.54-LS10.2`、`DIP8`、`8-DIP`、
  `SOIC-8`、`SOP-8`、`TSSOP-20`、`QFN-32`、`LQFP-48` 等，取值域 4–64；
- 声明脚数 = `max(最大已连脚号, 封装脚数)`，因此「只连 1、2 脚的 DIP8」现在就是 8 脚，
  而未使用脚在 DRC 里仍按「未使用引脚」警告处理，不影响连通性判定；
- 非 IC 位号不受影响（电阻、电容、三极管、接插件按网表走），`TO-92-3`、`SOT-23` 不会被误读成 92 / 23 脚；
- 顺带修正：DIP 的封装名带上脚数（8 脚仍叫 `DIP`，其余 `DIP14` 等）。此前同一工程里 DIP8 与 DIP14
  共用一个内部封装定义，脚号会取并集，导致两个都变 14 脚。

**验证**：`DIP-8_L9.8-W6.5-P2.54-LS10.2` + 仅 1、2 脚入网 → 导入后该元件 8 脚，
「生成元件」得到 `kind=dip / 8 脚` 的 3D 模型；修复前是 2 脚。回归测试 11 项覆盖 DIP8 / DIP14、
完全未连、稀疏脚、超出封装的脚号以及 `TO-92-3` 反例。

## 上一版（3.2.4）的两项修复

1. **改网后的「假短路」**：在网络面板把引脚划到别的网络时，原来所属网络的走锡没清，
   仍压在该引脚孔上 → 重跑 DRC 报「错网短路 / 网络间短路」。现已统一清理受影响网络的铜箔并给出提示。
2. **自定义封装面板缩略图**一直显示占位图，现能正常显示 3D 模型预览。

## 自 v3.0.0 以来的主要变化（摘要）

- **自定义封装**：2×N 开发板 / 模块封装，脚数与排距可调，可保存复用，放不下时直接禁用放置；
- **软件内网络编辑**：新建 / 删除网络、增删引脚，并可在 3D 板上**点引脚拾取**直接连线；
- **Multisim 报告导入**：Wire List + Cross Reference 双报告，电源符号忽略、多单元归并、字母脚重编号；
- **嘉立创导入持续修正**：电解 / 普通电容区分、轻触按键字母脚（`SW1-A/B`）、按键类别识别；
- 工具栏新增「透视」按钮；修复引脚点选坐标公式写反导致默认视角点选失效。

## 升级注意

- **重新导入一次网表**才能享受脚数修正（已导入的旧工程里，元件脚数是导入时写死的，
  可在右侧属性面板手动改，或重新导入该网表）。
- 工程 JSON 向下兼容（v2.0.0 起均可打开）。
- 若旧版本里改过网络，升级后建议**重跑一次 DRC**。

## 已知限制

- 只支持洞洞板 / 面包板，没有过孔与多层；
- 网表来源：KiCad `.net`、嘉立创 Protel2 `.net`、Multisim 双报告；SPICE 不支持；
- 元件库 23 类，不认识 / 未给封装名且脚数无法推断的元件退化为排针，需在属性面板手动核对脚距；
- 元件没有镜像功能，只能 90° 旋转；
- AI 指令功能需要自备 API，仅在洞洞板「自动放置」对话框内。
