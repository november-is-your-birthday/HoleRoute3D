## 我改了什么

**兼容性**

- 支持嘉立创 EDA（专业版 / 标准版）导出的 Protel2 / 99SE 网表，README 里补了导出步骤
- 打包成解压双击即用的完整包（原版需要自己准备运行环境）

**界面与交互**

- 全量汉化，含 20 个 DRC 错误码与 17 条提示文案
- 顶部工具栏重排分组、窄屏可横向滚动；侧栏「元件 / 网络 / 引脚网络」默认收起
- 板子 / 顶层圈 / 底层圈 / 高亮圈四组配色可调，存 localStorage
- 元件库加 3D 缩略图与放大预览；右键旋转拆成 +90° / −90°

**功能**

- **继续布线**：保留已有走锡与跳线，只补未连通的网络（并查集判物理连通，已连网络跳过；既有走锡作为障碍）
- **飞线层**：视角翻到底面时显示，按连通块做 MST，可开关（localStorage 记忆）
- 清除布线（只清 routing，不动元件与网络）
- DRC 面板固定在「导入」下方，悬空引脚对应焊盘标灰而非报红

**算法**

只做了低风险部分，用离线 harness 做了消融验证：

- 放置阶段约 2.3× 提速（短路判定、WeakMap 缓存、预算参数收敛），结果质量不变
- 布线只保留「拉直（pull-tight）」，其余尝试（网络排序、拆线加码、连通度链式顺序）实测零收益，已回滚
- 想再降跳线只剩 PathFinder 类协商拥塞，风险高，暂时没做
