# v3.5.5 — PNP 三极管支持与元件库补全（内测版）

## 本版回答两个问题

### 1. PNP 三极管有没有问题？

旧版能生成三脚模型，但导入分类几乎一律写成 NPN，属性面板也不显示极性。
本版补齐 PNP 的识别、分类与显示：

- `.enet` 和 Multisim 导入可识别 S8550、2N3906、MMBT3906、TIP42 等常见 PNP 型号；
- 属性面板明确显示 `NPN` 或 `PNP`，同时保留封装、脚号、孔位和网络；
- 判不出极性时不硬猜；
- **PNP 与 NPN 的 E/B/C 角色定义相同，脚序不因极性而自动反转。**

### 2. 元件库是不是只有一种三极管？

旧库实际有 5 个封装条目，但都只有封装名、没有型号和 NPN/PNP 区分，也没有 SOT-23。
现在扩为 **6 类封装 × 2 种极性 = 12 个条目**：

| 封装 | NPN 示例 | PNP 示例 |
|---|---|---|
| TO-92 | S8050 | S8550 |
| SOT-23 | MMBT3904 | MMBT3906 |
| TO-39 | 2N2219 | 2N2905 |
| TO-220 | TIP41 | TIP42 |
| TO-3 | 2N3055 | MJ2955 |
| TO-247 | 2SC5200 | 2SA1943 |

从库中放置时会把型号和封装一起写入工程；同封装 NPN/PNP 的缩略图缓存键也已分开。

## 使用注意

- 黄色 E/B/C 字母仍是「按网表或封装常见排布暂标」；手选脚序后变白并保存。
- 同一封装的不同型号可能脚序不同，例如 TO-92 的 S8050 与 BC547 不应混用排布。
- 最终以具体型号的数据手册和实物为准；若不一致，在属性面板的「三极管脚序」下拉中修改。

## 验证

- 新增 PNP 专项回归 60 项，全部 22 套测试通过；
- 自动布线评分 **15476 零漂移**；
- 实机验证 12 个库条目、S8550 PNP 落板显示 `E-B-C`、MMBT3904 NPN 保持 SOT-23 的 `B-E-C` 脚号映射；
- 浅色界面下条目、属性文字与 3D 标注均可见，无条目覆盖。

## 安装

下载 `ProtoRoute3D-v3.5.5-cn-win-x64.zip`，完整解压后运行 `ProtoRoute 3D.exe`。
窗口标题显示 `ProtoRoute 3D v3.5.5 内测版` 即为本版。现有工程可直接打开。

仍为内测版，重要工程请随时导出 JSON 备份。
