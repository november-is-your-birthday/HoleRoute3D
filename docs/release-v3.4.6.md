# v3.4.6 三极管脚序：说 E 就是 E

## 问题

你报的是「三极管的发射极集电极基极和对应的封装上的引脚不一致」。查下来不是一个 bug，是三个叠在一起。

### 1. 选什么排布都不生效

软件里有一张字母表，按封装 + 你选的脚序查「脚1 应该是什么」。但 `to220`、`to3`、`to247`
三行，`EBC`、`CBE`、`BCE` 三个键**全部**返回 `B-C-E`：

```
to220: { EBC: ["B","C","E"], CBE: ["B","C","E"], BCE: ["B","C","E"] }   ← 三个键同一个答案
to92:  { EBC: ["E","B","C"], CBE: ["C","B","E"], BCE: ["B","C","E"] }   ← 这个是对的
```

所以你在 TO-220 上选「1=E 2=B 3=C」，软件照样把脚1 标成 `B`。TO-92 和 TO-39 没这个问题，
这也是为什么有些人遇到的错位更明显。

### 2. 四种封装根本没标字母

`zP`（TO-39）、`FP`（TO-220）、`tR`（TO-3）、`eR`（TO-247）四个建模函数没有接收引脚名参数，
3D 模型上一个字母都不显示。v3.3.0 当时声称做了「三极管标 E/C/B」，实际只改了 TO-92 和 LED，
其余留在半成品状态。你只能对着外部封装图数脚，数错了也没提示。

### 3. TO-92 中间那只脚的字母被模型自己挡住

字母是画在 3D 里的文字精灵，位置 `y=1.02, z=引脚+0.52`，而元件本体的包围盒是 `y 0.98–1.58`、
`z ±0.82`。从上方俯视时，中间那只脚（`x=0`）的字正好压在元件底下——**看不见**；
另外两个偏出整整一格，看着像标在隔壁的孔上。

## 改法

**① 脚序不再查表，就是逐脚角色。**
`EBC` 字面意思：脚1=E、脚2=B、脚3=C。跟封装无关，六种排布（`EBC`/`ECB`/`BCE`/`BEC`/`CBE`/`CEB`）各给各的答案。
属性面板的下拉从 3 项扩到 6 项。

**② 五种三极管封装全部标字母。**
新增统一的 `__lcPinLetters()`，`TO-92 / TO-39 / TO-220 / TO-3 / TO-247` 每只脚正上方都标出角色。
圆形封装（TO-39/TO-3）会把字往引脚外侧推，避免压在罐体上。

**③ TO-92 的字母挪到本体正上方、水平正对各自孔位。**
`y=1.85`（元件顶面 1.58 之上）、`z` 与引脚孔重合。俯视不会被挡，也不会偏格。器件名抬到 `y=2.3` 让开。

**④ 给出方向基准。**
TO-92 模型上加了一条**浅色扁平面**，那就是封装印字面——朝它就是「平面对自己」的方向。
属性面板多了一行对照：

```
脚1 E ｜ 脚2 B ｜ 脚3 C　（E-B-C）
基准：平面对自己、引脚朝下，从左→右为 1→2→3。实物顺序不同就换一种排布。
```

没指定脚序时显示 `1 / 2 / 3` 并提示该封装的常见排布（`本封装常见：B-C-E`），**绝不替你猜极性**。

## 实测（打包后程序，CDP 读 3D 精灵的坐标与文字）

| 检查 | 结果 |
|---|---|
| TO-92 `EBC` | x=8.5「E」 7.5「B」 6.5「C」，与 `pinOffsets` 逐脚对齐 |
| TO-92 `CBE` | x=8.5「C」 7.5「B」 6.5「E」 |
| TO-220 / TO-39 / TO-3 / TO-247 | 全部逐脚标出 E/B/C（改前一个字母都没有） |
| 标签高度 | `y=1.75`，本体顶面 `1.58` —— 俯视不再遮挡 |
| 标签水平位置 | `z` 与引脚孔重合，不再偏出一格 |
| 面板 | 下拉 6 项齐全；对照行与基准说明正常渲染 |

`pin_names.js` 从 34 项扩到 52 项：五种封装各选 `EBC`、六种排布互不相同且各含 E/B/C 一次、
推荐值不参与判定、对照行四种输入、无引脚 / `null` 不抛异常、四个封装都传 `pinNames`。
16 套测试全绿，`lint-lc --strict` 120 个函数，跑分 15476 零漂移。

## 怎么用

1. 选中三极管 → 右侧「元件属性」→「三极管脚序」；
2. 按你手上那颗的实际排布选（`TO-92` 的 S8050/9013 选 `1=E 2=B 3=C`，BC547 选 `1=C 2=B 3=E`；
   `TO-220` 主流是 `1=B 2=C 3=E`）；
3. 看 3D 上每只脚标的字母是否和封装图一致——不一致就换一种排布，直到对上。

**注意**：脚序是「脚号 → 角色」的映射，与元件怎么摆放、怎么旋转无关。元件转 180° 时，
脚1 跑到另一侧，字母跟着跑，这是对的——实物转过来，平面朝向也反了。
TO-92 上那条浅色扁平面就是用来分辨这个的。
