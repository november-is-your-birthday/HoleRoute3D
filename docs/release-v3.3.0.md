# 洞洞板布线 HoleRoute3D v3.3.0

> 洞洞板 / 万能板的 3D 元件摆放、反面走锡、跳线规划与 DRC 检查工具。
> 基于 [Tomjiang678/Perfboard-AutoRoute-3D-Windows](https://github.com/Tomjiang678/Perfboard-AutoRoute-3D-Windows) v2.0.0 二次开发，**非官方修改版**。

## 下载与安装（Windows x64，免安装）

1. 下载本页下方的 `ProtoRoute3D-v3.3.0-cn-win-x64.zip`（约 130 MB）；
2. **完整解压**到任意目录，例如 `D:\HoleRoute3D`；
3. 双击 `ProtoRoute 3D.exe`，不需要装 Python / Node / 任何运行时。

> 必须解压**整个目录**：程序依赖同目录的 `*.dll`、`*.pak`、`locales\`、`resources\`，只复制 exe 跑不起来。
> 首次运行可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可（本版无代码签名）。

窗口标题显示 **ProtoRoute 3D v3.3.0** 表示版本正确。

## 本版重点：多选与成组操作

### Ctrl 多选

按住 `Ctrl` 点击元件即可加选 / 减选，选中的元件都会亮起来。主选中（最后点的那个）仍用于属性面板，
取消某个元件时主选中自动回退到下一个，不会出现「选着选着面板空了」。

选中之后，**旋转、拔起、放回、删除、拖动都对整组生效**，操作手感和单个元件完全一样；
而且整组操作只记一步撤销——`Ctrl+Z` 一次全部回退，不用按好几次。

### 全部拔起

工具栏新增「全部拔起」（`Shift+U`）：一次把板上所有元件拔起来重新布局。
已有的走锡 / 跳线按你的选择**保留**，所以提示条会写明「重新放置后请重跑 DRC」；板上已有布线时会先确认一次。

### 空格顺时针旋转

元件拔起后按 `空格` 就是顺时针 90°，比记 `R` 的加减方向直觉得多。
元件还在板上时会提示「先拔起（U）再旋转」——这是有意的：旋转会改变引脚落孔，已布的铜箔就不再成立。

## 三极管 / LED 现在能看出引脚了

以前 3D 模型上只画一个「Q」，三极管三个脚只能靠数孔，很容易接反。现在：

- **TO-92 每个引脚直接标名字**（`E` / `B` / `C`，或退化为 `1/2/3`）；
- **LED 增加阴极短横线**，并标 `A` / `K`；
- 悬停或点击任意引脚，直接显示 `Q1.1（E） — 网络 $1N5`，不用再去网络面板里翻。

引脚名从哪来，按这个顺序取：**网表里带的真实引脚名 → 你在属性面板手选的脚序 → 就显示 1/2/3**。

> 为什么不直接猜？TO-92 的脚序有 `E-B-C` / `C-B-E` / `B-C-E` 好几种排布，从网表里推不出来。
> 猜错比不标更危险，所以默认只显示脚号，你在右侧「元件属性 → 三极管脚序」里选一次，标注立刻刷新。

## 关于「极性」的说明

**自动布线不需要区分极性，软件本来就没区分，这是正确的。** 电阻、电位器、无极性电容的两端在拓扑上完全等价，
布线器只关心「哪些孔要连在一起」，与谁是一脚二脚无关。

真正会出问题的是**导入时的分类**，本版修了两处：

1. **无极性电容被当成电解电容**：`1uF` 的涤纶 / 薄膜 / CBB / MLCC 电容，以前会因为「值里有 uF」
   被判成电解电容，3D 里画上 +/− 和色带，看着像接反了。现在 `CBB / FILM / MLCC / 涤纶 / 薄膜 / 独石 /
   陶瓷 / NP0 / NPO / X7R / X5R / C0G` 一律判为无极性，同时保留 `CP / POLAR / 电解 / ELE / TANT /
   RADIAL / RB / µF 且非贴片尺寸` 作为「确实是电解」的证据。
2. **三极管字母脚被按字母序重编号**：`E/B/C` 会变成 `B=1, C=2, E=3`。本版的脚序下拉就是给这件事兜底的。

## 四个「看着像玄学」的 bug

### 1. 开了透视还是看不到对面的走线

**不是透明度的问题。** 板体早就设了 `opacity 0.18 + depthWrite:false`，真正的原因是渲染循环里
`MR()` 每帧都按相机高度把「背面走线组」整组 `visible = false`——透视只让板子变透明，线本身还在被隐藏。

现在透视时**两侧走线同时可见、飞线也可见**，并且走线在透视下打开深度测试（会被元件正确挡住，而不是穿透一切），
板体也不再投影。这才是 X-ray 该有的样子。

### 2. 删线删不掉跳线

擦除模式的判定是「点击孔位坐标是否等于跳线的端点孔」。但点击坐标来自「屏幕射线 → 板平面 → 取整到孔」，
永远是孔；跳线是跨两孔的拱形线，点拱起的弧线本身，得到的是**弧下方的那个孔**——永远不相等，而且什么提示都没有。

现在跳线带了自己的 id 标记，射线打中弧线就能删；孔位判定优先、id 兜底，删不到时会明确提示。
被不透明板体挡住的跳线不会被误删（按最近命中距离判断，开透视后放开）。

### 3. 点「继续布线」，飞线全没了

实测下来有两层原因：

- **手工跳线被丢掉**：布线器内部那个函数只在面包板分支读取「已有跳线」参数，洞洞板分支完全忽略，
  于是「保留已有走锡 / 跳线」的承诺只兑现了走锡那一半。现在会合并新旧跳线并去重
  （实测 5 条手工 + 10 条新建 → 15 条，一条不少）。
- **飞线"消失"是视角问题**：走锡画在板背面，而顶部视角下整个背面组被隐藏，你只看到飞线消失、
  看不到新增的铜箔，自然觉得「什么都没干」。透视修复之后就能看见了。

现在继续布线还会直接告诉你结果：**新增走锡 N 段、跳线 M 条；仍有 K 个网络未连通**（K=0 时明确说全部连通）。

### 4. 撤销只能退 50 步

上限提到 **200 步**，并补上了**重做**（`Ctrl+Shift+Z`）。此前只有「撤销」一个图标按钮，按错了没得回。

## 其他改动

- 术语统一：元件菜单的「移除」改为「**拔起**」，状态显示「已在板上 / 已拔起」；
  网络面板里「点引脚建网络」的按钮由「拾取」改为「**点选引脚**」——两个概念不再共用一个词。
- 组合旋转按「各自绕自己的 1 脚」旋转，引脚一定落在整孔上，不会出现半孔错位。

## 升级注意

- **工程数据向下兼容**，直接打开即可；
- 你之前手工设过的跳线和走锡都不会丢，但**升级后建议重跑一次 DRC**（本版改了几处与铜箔相关的清理逻辑）；
- 电容的无极性判定只影响**新导入**的网表；已经在工程里的元件，`kind` 是导入时写死的，
  如果发现某个电容被画上了 +/−，在属性面板里把它的参数改一下或重新导入该网表即可；
- 三极管脚序需要在属性面板里**逐个设置一次**，每个型号选一次即可（设置会存进工程 JSON）。

## 已知限制

- 只支持洞洞板 / 面包板，没有过孔与多层；
- 网表来源：KiCad `.net`、嘉立创 Protel2 `.net`、Multisim 双报告；SPICE 不支持；
- 元件库 23 类，不认识 / 未给封装名且脚数无法推断的元件退化为排针，需在属性面板手动核对脚距；
- 元件没有镜像功能，只能 90° 旋转；
- **拖动已放置的元件仍需先拔起**（`U` / `Shift+U`）；
- 组合拖动时只有被拖的那个元件实时跟手，其余选中元件在松手时跳到目标位置；
- 三极管脚序默认「未指定」（只显示 1/2/3）——不同型号排布不同，软件选择不猜；
- AI 指令功能需要自备 API，仅在洞洞板「自动放置」对话框内。
