# v3.4.4 — DRC 报错能定位到具体位置

之前 DRC 只给一句「网络间短路 @ 13,42：MANUAL、$1N11」，既不知道这个孔上是哪个元件的哪只脚，
也没法点过去，只能在板上数行列找。这一版把「哪条错、错在哪、涉及哪只脚」一次说清。

## 每条错误都带定位

- **孔位**：右侧绿色标签，例如 `13,42`。
- **涉事引脚**：`位号.脚号（网络）`，例如 `C7.2（$1N11）`。
- 「底层走锡重叠 / 交叉」这类只有**一条边**的错误，原来连坐标都没有，
  现在补齐两端孔位：`8,23 ↔ 8,24`。
- 顶部按错误码给计数标签（`网络间短路 ×5`、`应连未连 ×12`…），一眼看出问题集中在哪一类规则。

## 点一下就能跳过去

点任意一条错误，相机会沿当前视角方向平移并拉近到那个孔（距离收到 7–16 格），
同时在孔上打一个红球标记——**透视/背面视角下也看得见**（标记关掉了深度测试）。
「清除标记」一键收回。

## 列表不再截断

原来是「前 12 条错误 / 前 8 条警告」，超出的直接消失。现在错误在前、警告在后、
整表可滚动，超过 120 条才折叠并提示剩余条数。底部「复制全部」会把整份清单
连同孔位与引脚一起复制成文本，方便发给别人或留存。

## 已知限制

- 像 `DIP_PIN_GEOMETRY` 这类纯几何说明的警告本来就没有具体孔位，面板会省略孔位标签，点击只提示无法定位。
- 定位只移动视角并打标记，不会自动切换到对应的编辑模式；需要改线时仍要自己按 `S` / `J` / `E`。
