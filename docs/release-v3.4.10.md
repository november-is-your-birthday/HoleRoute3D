# v3.4.10 三极管标注贴到本体上，模型恢复原样

## 你反馈的两件事

**① 「不是整个模型都变化了」** —— 确实是我的问题。

v3.4.6 为了标出 TO-92 的「印字面」（判断 1 脚在哪边要用），我在元件正面额外贴了一条
浅色窄条（1.34 × 0.24 的方块）。那东西原模型没有，看起来就是「元件上多了一根不认识的白杠」。
**已删除**，本体几何恢复成上游原样。

**② 「标记要在主体上，不是悬空在引脚上」** —— 位置也确实是错的。

原来五个封装的字母统一挂在 `y=1.02`（板面高度、贴着引脚），TO-92 更夸张，在 `y=1.85` 的空中。

## 顺带查出来的第三个问题：字太小

上一版我自己验收时没放大截图，只看坐标「在位置上了」就放过去了。这次放大后才发现：
字母实际只有 **0.07 格高**，在黑色本体上就是三个白点。

原因：复用了画位号用的 `Un()` —— 它的 canvas 是 256×64（4:1），Sprite 又按
`scale.y = scale.x × 0.25` 压扁，`scale=0.46` 时真实字高被压到 0.07 格。

改法：新增 `__lcPinSprite()`，**128×128 方形画布、92px 字号**，同样 scale 下字高约 **0.33 格**，
约为原来的 5 倍，和位号 `Q` 一个量级。

## 实测

把相机推到 Q1 跟前进景截图，再裁切放大：

```
Q1（TO-92，未指定脚序 → 暖黄暂标）
  C  B  E  三个字母清晰落在黑色本体顶面内
  本体 x 范围 6.68–8.32  ←→  字母 6.95 / 7.50 / 8.05
  本体顶面 y=1.64          ←→  字底 1.64（贴面）
  本体上多余几何：0 个
```

字母顺序视觉上是 `C B E`（左→右），因为这颗元件旋转了 180°，脚 1 落在右侧——
和实物转过来说是一样的，不是错位。

## 一个说明：为什么字是「立」在表面上

字母用的是 Sprite（永远面向观察者），不是贴图网格。代价是斜视时看起来像立着的小牌子，
好处是无论元件怎么转、相机从哪看，字都能读。

改用真正的贴图网格会随表面透视、更像丝印，但元件旋转 180° 时字会跟着倒过来
（构建模型时读不到元件最终旋转角）。两害相权，先选「永远读得清」。

如果你更想要「像丝印一样平贴、哪怕会倒」，说一声，我改成网格贴片。
