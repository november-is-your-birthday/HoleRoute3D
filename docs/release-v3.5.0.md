# v3.5.0 — 新手教程与界面优化（内测版）

> 仍是内测版，已知 / 未知缺陷都不少。重要工程请随时导出 JSON 备份。

## 新增：内置新手教程

顶栏右侧新增常驻黄色 **「新手教程」** 按钮，快捷键 **`F1`**。没有新建工程时也能查看，
内容完全离线，不需要联网。

教程按真实工作流程分 7 章：

| 章节 | 内容 |
|---|---|
| 01 快速上手 | 新建工程 → 导入网表 → 生成并摆放元件 → 自动布线 / DRC → 导出 JSON |
| 02 导入网表 | 嘉立创 `.enet` 优先；Protel / KiCad `.net`、Multisim 双报告的导出路径 |
| 03 摆放与视角 | 自动放置、Shift 拖动、Ctrl 多选、旋转、板尺寸输入、透视 |
| 04 布线与检查 | 自动 / 继续布线、飞线、走锡、跳线、删线、DRC 与焊接前最低检查项 |
| 05 引脚与极性 | 三极管 E/B/C 白字与暖黄暂标、二极管 / LED 黑色负极环、悬停查网络 |
| 06 保存与施工 | JSON 备份与恢复、撤销、建议施工顺序、通电前检查 |
| 07 快捷键与排错 | 22 个快捷键速查、导入后看不到元件等五类常见问题 |

**特意写明的两个易错点：**

1. 导入网表后**必须再点「生成元件 G」**，导入成功不等于元件已出现；
2. 走锡通常画在板背面，**按 `T` 透视**才能从顶部看到。

操作方式：左侧目录直达章节，`←` `→` 切换，`Esc` 关闭；窄窗口自动改为横向目录，
深色主题有独立配色。弹窗支持键盘焦点循环，关闭后回到打开教程的按钮。

## 界面优化

本轮只做小范围优化，**没有改变主布局和既有操作流程**：

- 顶栏由 46 px 增至 52 px，主要按钮从 28 px 增至 32–34 px，更容易点中；
- 工具栏按钮补充明确的悬停、选中、禁用状态，快捷键提示在悬停时可见；
- 所有按钮使用 2 px 键盘焦点框，深色 / 浅色下均清晰；
- 工具栏按钮补充无障碍名称与开关状态，读屏软件能正确识别；
- 深色模式单独校正工具栏对比度；
- 1440×900 与 720×720 实测无页面横向溢出，工程内 F1 正常打开教程。

没有重排左侧栏、3D 视口、属性面板或工具栏分组。如果你希望改成更大幅度的布局重构，
请先单独提出，我会给出方案再动手。

## 升级说明

1. 下载 `ProtoRoute3D-v3.5.0-cn-win-x64.zip`，完整解压；
2. 先导出当前工程 JSON 备份，再替换旧目录中的程序文件；
3. 双击 `ProtoRoute 3D.exe`，窗口标题应显示 **ProtoRoute 3D v3.5.0 内测版**；
4. 首次使用按 `F1` 查看教程。
